# 最终科研总结

## 项目定位

题目建议：**面向高相似身份风险的人脸验证研究——传统机器学习基线、压力测试与跨域分析**

本项目不是复现某篇论文，也不是宣称已经解决双胞胎识别。研究从门禁中的一对一人脸核验出发，提出四个连续问题：

1. 小样本、高维像素条件下，PCA维数应如何选择？
2. PCA距离、逻辑回归、线性SVM和RBF-SVM谁更稳定？
3. 普通随机异人配对是否低估高相似身份的错误接受风险？
4. ORL受控场景形成的方法结论能否迁移到LFW自然场景？

## 完整技术路线

```text
数据审计
  → 按身份隔离训练/验证/测试
  → 同人正配对与异人负配对
  → 训练集拟合PCA
  → 距离 / 逻辑回归 / 线性SVM / RBF-SVM
  → 内部交叉验证选择k、C、gamma
  → 冻结模型与门禁阈值
  → 一次性ORL测试
  → 高相似身份代理压力测试
  → LFW身份隔离十折迁移验证
```

所有学习型处理只拟合训练数据。验证数据用于选参数或阈值，测试数据只负责最后评分。原始结果、逐折分数、图表和决策均保留，失败结果没有删除。

## 主要结果

### 1. ORL受控场景

- 10,304维原始像素经过粗搜索、细搜索和一标准误差规则，选择80维PCA。
- 开发阶段RBF与线性SVM的EER均为16.94%，RBF仅凭AUC微弱差异成为预注册候选。
- 一次性最终测试没有维持该排序：PCA距离EER为11.67%、AUC为0.9567，优于RBF的13.06%和0.9367。
- 结论不是“RBF最优”，而是简单距离在当前小样本受控数据上更稳定，开发集微弱排名不可靠。

### 2. 高相似身份代理压力测试

- 从8个验证身份的28个异人身份对中，按PCA身份中心选择最近7对，共700条困难负样本。
- 从剩余身份对无放回抽取700条普通负样本作为等量对照。
- 四模型普通组FMR为0.14%—0.57%，困难组升至5.86%—6.86%，风险放大12—41倍。
- PCA的41倍受PCA空间选样与普通组仅1次错误接受影响，不能据此称PCA最差；更稳妥的绝对FMR增量约为5.4—6.3个百分点。

### 3. LFW自然场景迁移

- 审核13,233张图片、5,749个身份及9,200条官方配对，未发现损坏或缺失引用。
- 使用 `pairs.txt` 的身份隔离十折，每轮8折训练、1折校准阈值、1折测试；各组身份、图片和配对均不重叠。
- ORL冻结方法的平均EER全部约37%—38%，没有分类器稳定超过距离。
- 在约1.2%的FMR下，所有方法FNMR都超过90%，不具备门禁可用性。
- 这说明像素PCA主要保留总体变化，无法区分身份变化与光照、姿态、表情、遮挡变化；浅层分类器无法稳定弥补表示层失配。

## 研究贡献

1. 将课程式多分类任务重新定义为与门禁一致的一对一人脸验证问题。
2. 建立身份隔离、预处理防泄漏、参数预注册、最终测试封存和逐折复现的完整流程。
3. 用身份级困难负样本证明平均随机负样本会掩盖高相似身份的尾部错误接受风险。
4. 通过第二数据集证实受控场景结论不能直接外推，并定位传统像素PCA的表示局限。
5. 对没有支持最初假设的结果如实报告：RBF没有稳定领先，跨域迁移也没有成功。

## 可以说与不能说

可以说：

- 完成了传统机器学习人脸验证基线、参数选择、风险压力测试和跨数据集实验。
- 在本次ORL最终测试中，PCA距离优于三个学习分类器。
- 高相似身份代理显著集中错误接受风险。
- ORL冻结方法在LFW身份隔离评测中迁移失败。

不能说：

- 已经解决或实际测试了双胞胎识别。
- 当前系统能够部署到真实门禁。
- PCA距离在所有人脸数据上都优于SVM。
- 41倍风险可以直接代表真实双胞胎风险。
- 只凭10折均值的零点几差异证明某个分类器显著更优。

## 局限与后续工作

- ORL只有40个身份，最终测试只有8个身份，模型排名不够稳定。
- ORL没有双胞胎或亲缘标签，高相似组只是算法代理。
- 困难组由PCA空间选择，对PCA距离存在选择偏差。
- LFW官方配对正负平衡，不代表真实门禁中大量异人尝试的自然比例。
- 当前特征主要是灰度像素PCA，没有系统比较LBP、HOG、LDA等传统判别特征。
- 后续可先开展严格隔离的LFW域内参数适配，再引入LBP/HOG与LDA，最终在获得授权的双胞胎数据上验证。

## 推荐复试PPT结构

1. 项目题目与一句话结论。
2. 双胞胎门禁动机，但明确当前研究边界。
3. 从人脸辨识到一对一验证的问题定义。
4. 数据集职责：ORL建立基线，LFW检查迁移。
5. 身份隔离、训练/验证/测试与防泄漏。
6. PCA通俗原理与80维选择过程。
7. 四类模型及参数搜索设计。
8. ORL最终结果：开发候选未在测试保持领先。
9. 高相似身份代理：FMR放大12—41倍。
10. LFW严格8/1/1十折协议。
11. LFW迁移结果：四模型均失败。
12. 结论、贡献、局限与未来工作。
