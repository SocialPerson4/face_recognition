# 人脸验证科研计划

## 项目题目

面向高相似身份区分的人脸验证方法研究

副标题：基于 PCA 与支持向量机的参数选择及误差分析

## 研究动机

门禁人脸核验需要判断现场人脸是否与登记身份一致。双胞胎等高相似身份说明，普通测试中的高准确率可能掩盖错误接受风险。本研究从传统机器学习出发，建立可解释、可复现的人脸验证基线，并研究模型在高相似身份上的性能边界。

## 研究问题

1. PCA 维数如何影响验证性能、稳定性和计算成本？
2. 距离阈值、逻辑回归、线性 SVM 与 RBF-SVM 哪种模型更合适？
3. 高相似负样本相对普通随机负样本会增加多少错误接受风险？
4. ORL 上形成的方法结论能否在更复杂的 LFW 图像上保持？

## 研究轮次

### 第一轮 ORL 基线与参数选择

- 把多分类数据重新组织为同一人与不同人的配对验证任务。
- 按身份或图像组进行无泄漏划分。
- 比较原始像素距离、PCA 距离、逻辑回归、线性 SVM 和 RBF-SVM。
- 对 PCA 维数先粗搜索，再在优良区间细搜索。
- 计算 FMR、FNMR、EER、ROC-AUC、运行时间和多轮波动。

### 第二轮 高相似困难负样本

- 冻结第一轮实验协议和候选模型。
- 构造普通随机负样本作为对照条件。
- 使用提前确定且独立于候选分类器的规则构造高相似负样本。
- 比较两类负样本的 FMR，并分析风险倍数与选择偏差。
- ORL没有亲缘标签，因此将其限定为高相似身份代理压力测试。

### 第三轮 LFW 复杂条件验证

- 沿用已经确定的研究问题和评价规范。
- 使用官方身份隔离十折，按8折训练、1折校准阈值、1折测试轮转。
- PCA在训练折重新拟合，但k与分类器超参数冻结自ORL。
- 分析传统方法面对姿态、光照、表情和图像质量变化时的性能下降。

## 最终研究结论

- ORL受控条件下，80维PCA距离最终测试EER为11.67%，开发阶段的RBF微弱优势没有保持。
- 高相似身份代理使四模型FMR从0.14%—0.57%升至5.86%—6.86%，说明普通随机负样本低估尾部风险。
- LFW身份隔离十折中，四种ORL冻结方法EER均约37%—38%，严格门禁FNMR均超过90%，直接迁移失败。
- 当前成果是可复核的传统机器学习基线、风险分析和跨域局限证据，不是可部署系统，也不包含真实双胞胎结论。

## 研究原则

- Python 是唯一正式实现。
- PCA、缩放器、模型和阈值只能使用训练数据拟合。
- 不预设 RBF-SVM 或任何方法必然获胜。
- 不因结果不理想而删除实验或改变测试规则。
- 双胞胎是动机和未来工作，当前没有双胞胎数据，不声称已验证该场景。
- 每个阶段保存配置、原始结果、图表和决策记录；对应演讲词只保存在本机忽略目录。
