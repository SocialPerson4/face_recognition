# 项目立项演讲词

## 约九十秒版本

我计划研究高相似身份条件下的人脸验证问题。这个问题来自门禁场景：系统需要判断现场人脸是否与登记身份一致。普通不同身份之间往往外观差异较大，因此一般测试得到的高准确率，可能低估双胞胎或其他高相似身份带来的错误接受风险。

本项目先从传统机器学习出发。原因是 PCA 和 SVM 的计算过程、参数和特征都比较容易解释，也适合在小样本条件下进行大量重复实验。我不会预先固定 PCA 维数，也不会预设 RBF-SVM 一定最好，而是在训练数据内部比较不同维数、距离方法、线性模型和非线性模型。

研究分为三个阶段。第一阶段在 ORL 数据集上建立无泄漏的人脸验证基线，重点研究 PCA 维数和分类器选择。第二阶段构造普通随机负样本与高相似困难负样本，比较二者的错误接受率，并分析模型为什么会把不同身份判断为同一人。第三阶段使用更复杂的 LFW 数据，检查前面形成的结论能否适应真实网络图像中的姿态、光照和表情变化。

双胞胎是本研究的现实动机，但目前没有可用的双胞胎数据，因此我不会声称已经解决双胞胎识别。这个项目当前要回答的是：传统 PCA 与 SVM 方法在什么条件下有效，参数应该如何选择，以及面对高相似身份时会暴露什么安全边界。

## 约三十秒版本

本项目研究门禁中的高相似身份人脸验证。普通数据可能低估双胞胎等相似身份造成的错误接受风险，因此我先使用可解释的 PCA 和 SVM 建立验证基线，通过训练集内部实验选择 PCA 维数和分类模型，再比较普通负样本与高相似负样本的错误接受率。最后使用 LFW 检查传统方法在复杂图像条件下的局限。当前研究不声称已经解决双胞胎识别，而是重点分析传统方法的参数选择和安全边界。

## 可能追问

### 为什么不直接使用深度学习

第一阶段的目标是理解完整实验流程和各模块的实际贡献。PCA 与 SVM 可解释、计算成本较低，适合大量重复实验，也能为后续深度特征提供透明基线。

### 为什么双胞胎只是动机

权威双胞胎数据需要机构许可，当前无法取得。没有真实数据就不能宣称完成双胞胎验证，因此项目把结论限制在高相似身份风险，并把双胞胎测试列为未来工作。

### 如果传统方法表现很差怎么办

表现下降本身也是结果。我们会分析下降发生在哪类样本、哪些参数最敏感，以及全局 PCA 特征是否遗漏局部纹理，然后再决定是否引入 LBP 等改进。
